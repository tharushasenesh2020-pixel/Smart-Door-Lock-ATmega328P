# Smart Door Lock System using ATmega328P

## Project Overview

This project is a smart door lock system developed using the **ATmega328P microcontroller**. The system provides secure access using a **4x3 keypad** and also supports **Bluetooth communication** through an HC-05 module.

The system uses an **EEPROM** to store the user PIN, allowing the PIN to remain stored even when the power is removed. A **16x2 I2C LCD** is used to display system messages and lock status.

An Android application was also developed to communicate with the door lock through Bluetooth and provide remote lock and unlock control.

## System Operation

### PIN Authentication

1. The user enters the PIN using the 4x3 keypad.
2. The ATmega328P compares the entered PIN with the PIN stored in EEPROM.
3. If the PIN is correct, the door lock is activated.
4. If the PIN is incorrect, access is denied.
5. The LCD displays the corresponding system status.

### Bluetooth Control

The HC-05 Bluetooth module provides serial communication between the ATmega328P and the Android application.

The Android application can send commands to the microcontroller to control the lock.

Example commands:

```text
1 → Lock
0 → Unlock
```

## ATmega328P Pin Configuration

| Component        | ATmega328P Pin |
| ---------------- | -------------- |
| HC-05 TX/RX      | PD0 / PD1      |
| Lock Control LED | PB0            |
| I2C SDA          | PC4            |
| I2C SCL          | PC5            |
| LCD I2C Address  | 0x27           |

> Pin assignments may vary depending on the hardware version of the project.

## Project Development

The hardware system was designed around the ATmega328P microcontroller. The keypad is used for local authentication, while the HC-05 module provides Bluetooth communication with the Android application.

The solenoid lock is controlled using a transistor switching circuit. A protection diode is used to protect the switching circuit from the voltage generated by the solenoid coil.

The Android application provides an additional interface for controlling and monitoring the lock.
